WSO2 API Platform works alongside Mistral AI. Govern traffic to Mistral models, and use Mistral embeddings for semantic caching and guardrails.

## AI Gateway with Mistral models

Route, secure, and govern traffic to Mistral AI models through WSO2 AI Gateway.

### Mistral as an LLM provider

Register the Mistral API with the gateway, which stores the API key on behalf of your applications.

- [Create an AI API for Mistral](../create-api-proxy/third-party-apis/ai-apis/providers/mistral.mdx) Cloud console

- [Configure an LLM provider](docs:ai-workspace/cloud/guides/llm-providers/configure-provider/#authentication) AI Workspace
- [AI Workspace quickstart with Mistral](docs:ai-workspace/cloud/get-started/quickstart/) AI Workspace

- [MistralAI provider](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/gateway-artifacts/llm-provider/supported-providers/mistralai/) AI Gateway
- [Configure an LLM provider](https://wso2.com/api-platform/docs/ai-workspace/1.0.0/llm-providers/configure-provider/#authentication) AI Workspace

### OpenAI-format requests

Keep clients on the OpenAI request format while the gateway routes to Mistral.

- [Call Mistral AI through the gateway](docs:ai-workspace/cloud/guides/using-sdks/#mistral-ai) AI Workspace

Semantic caching and the semantic prompt guard compare prompts by meaning, and can use a Mistral embedding model that you set in the policy or gateway configuration.

- [Semantic cache policy](docs:ai-workspace/cloud/guides/policies/other-policies/semantic-cache/) AI Workspace
- [Semantic prompt guard policy](https://wso2.com/api-platform/policy-hub/policies/semantic-prompt-guard) Policy Hub

- [Semantic caching](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/semantic-caching/) AI Gateway
- [Embedding providers for semantic caching](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/setup-and-deployment/production-deployment/ai-workload-tuning/#provision-infrastructure-for-semantic-caching) AI Gateway

Routing, token limits, cost control, and the gateway's other policies work the same way for every provider. See the [AI Gateway documentation](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/overview/).

## Architecture and responsibility model

WSO2 API Platform and Mistral AI split the work like this:

| Scenario | WSO2 role | Mistral role | Runtime traffic |
| --- | --- | --- | --- |
| Applications calling Mistral models | Proxies and governs LLM requests | Hosts the models | Goes through WSO2 AI Gateway to Mistral |
| Semantic caching and guardrails | Runs the cache or guardrail policy | Returns embeddings for each prompt | The gateway calls the Mistral embeddings API alongside each request |
