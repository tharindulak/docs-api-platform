## AI Gateway with Gemini models

Route, secure, and govern traffic to Gemini models through WSO2 AI Gateway, including traffic from Gemini CLI.

### Gemini as an LLM provider

Register the Gemini API with the gateway. Applications call the gateway and never see the Gemini API key.

- [Configure an LLM provider](docs:ai-workspace/cloud/guides/llm-providers/configure-provider/#authentication) AI Workspace
- [Call Gemini through the gateway](docs:ai-workspace/cloud/guides/using-sdks/#gemini) AI Workspace

- [Gemini provider](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/gateway-artifacts/llm-provider/supported-providers/gemini/) AI Gateway
- [Configure an LLM provider](https://wso2.com/api-platform/docs/ai-workspace/1.0.0/llm-providers/configure-provider/#authentication) AI Workspace

### OpenAI-format requests

Keep clients on the OpenAI request format. A transformer policy converts requests and responses for Gemini.

- [OpenAI-format compatibility](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/gateway-artifacts/llm-provider/supported-providers/gemini/#openai-format-compatibility) AI Gateway
- [OpenAI to Gemini transformer policy](https://wso2.com/api-platform/policy-hub/policies/openai-to-gemini-transformer) Policy Hub

Routing, token limits, cost control, and the other AI Workspace policies work the same way for every provider. See the [AI Workspace overview](docs:ai-workspace/cloud/).

Routing, token limits, cost control, and the gateway's other policies work the same way for every provider. See the [AI Gateway documentation](https://wso2.com/api-platform/docs/ai-gateway/2026.09.24/overview/).

## Architecture and responsibility model

WSO2 API Platform and Google split the work like this:

| Scenario | WSO2 role | Google role | Runtime traffic |
| --- | --- | --- | --- |
| Gemini CLI through AI Gateway | Authenticates developers and applies guardrails, rate limits, and analytics | Hosts the Gemini models and bills the API key | Goes through WSO2 AI Gateway to the Gemini API |
| Applications calling Gemini models | Proxies and governs LLM requests | Hosts the Gemini models | Goes through WSO2 AI Gateway to the Gemini API |
| Gateway telemetry in Google Cloud | Emits metrics and traces from the gateway | Stores and displays the telemetry | The collector sends telemetry to Google Cloud without affecting API traffic |
