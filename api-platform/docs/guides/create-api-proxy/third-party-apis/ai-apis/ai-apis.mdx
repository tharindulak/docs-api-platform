AI Gateway enable seamless integration of artificial intelligence services into applications using **API Platform**. By creating an AI API, users can connect with specific AI service providers that best suit their needs.

## Providers

The AI Gateway is a specialized gateway in API Platform, designed for seamless integration with leading AI platforms:

- [OpenAI](./providers/open-ai.mdx)
- [Azure OpenAI](./providers/azure-ai.mdx)
- [Anthropic Claude](./providers/claude.mdx)
- [Mistral](./providers/mistral.mdx)
- [AWS Bedrock](./providers/awsbedrock.mdx)

## Policies

It allows developers to create native APIs for these services directly from the API Platform Console, with advanced features like security, token-based rate limiting, semantic caching, guardrails policies for content safety all out of the box.

- [Token Based Rate Limiting](./policies/token-ratelimit.mdx)
- [Guardrails](./policies/guardrails/guardrails.mdx)
- [Semantic caching](./policies/semantic-cache.mdx)
