## Create an API workflow

<Anchor id="opIdcreateApiWorkflow" />

`POST /views/{viewId}/api-workflows`

> Code samples

```bash

curl -X POST https://localhost:9543/api-portal/api/v0.9/views/{viewId}/api-workflows \
  -H 'Authorization: Bearer {access_token}' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -d @payload.json
```

Creates an API workflow in the selected view. If `id` is omitted, the service generates one from the display name. `ARAZZO` content is parsed from JSON or YAML; invalid Arazzo content returns a bad request.

> Payload

```json
{
  "displayName": "Weather onboarding",
  "id": "weather-onboarding",
  "description": "Guides users through the Weather API onboarding workflow.",
  "contentType": "ARAZZO",
  "apiWorkflowDefinition": {
    "arazzo": "1.0.1",
    "info": {
      "title": "Weather onboarding",
      "version": "1.0.0"
    },
    "workflows": []
  }
}
```

### Authentication

This operation requires a **Bearer JWT** access token in the `Authorization` header. Required scopes (the token must carry at least one of): \`dp:api_workflow:create\`, \`dp:api_workflow:manage\`

### Parameters {#create-an-api-workflow-parameters}

|Name|In|Type|Required|Description|
|---|---|---|---|---|
|body|body|[APIWorkflowCreateRequest](./schemas.mdx#schemaapiworkflowcreaterequest)|true|API workflow creation payload. Use `contentType` `ARAZZO` for JSON/YAML workflow content or `MD` for Markdown workflow content.|
|viewId|path|string|true|The view's handle (unique per org). Not the internal database uuid.|

> Example responses
>
> 201 Response

```json
{
  "id": "workflow-12345",
  "displayName": "Weather onboarding",
  "status": "PUBLISHED"
}
```

> 400 Response

```json
{
  "message": "string"
}
```

### Responses {#create-an-api-workflow-responses}

|Status|Meaning|Description|Schema|
|---|---|---|---|
|201|[Created](https://tools.ietf.org/html/rfc7231#section-6.3.2)|Created API workflow summary.|[APIWorkflowCreateResponse](./schemas.mdx#schemaapiworkflowcreateresponse)|
|400|[Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1)|JSON message response.|[MessageResponse](./schemas.mdx#schemamessageresponse)|
|409|[Conflict](https://tools.ietf.org/html/rfc7231#section-6.5.8)|JSON message response.|[MessageResponse](./schemas.mdx#schemamessageresponse)|
|500|[Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1)|JSON message response.|[MessageResponse](./schemas.mdx#schemamessageresponse)|

## List API workflows

<Anchor id="opIdgetAllApiWorkflows" />

`GET /views/{viewId}/api-workflows`

> Code samples


## Generate an API workflow agent prompt

<Anchor id="opIdgeneratePrompt" />

`POST /views/{viewId}/api-workflows/generate-prompt`

> Code samples

```bash

curl -X POST https://localhost:9543/api-portal/api/v0.9/views/{viewId}/api-workflows/generate-prompt \
  -H 'Authorization: Bearer {access_token}' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -d @payload.json
```

Generates the default agent prompt text for a proposed API workflow using the supplied name, description, APIs, and view context.

> Payload

```json
{
  "displayName": "Weather onboarding",
  "description": "Guides users through the Weather API onboarding workflow.",
  "apis": [
    {}
  ],
  "orgHandle": "acme",
  "viewName": "default",
  "id": "weather-onboarding"
}
```

### Authentication {#authentication_5}

This operation requires a **Bearer JWT** access token in the `Authorization` header. Required scopes (the token must carry at least one of): \`dp:api_workflow:create\`, \`dp:api_workflow:manage\`

### Parameters {#generate-an-api-workflow-agent-prompt-parameters}

|Name|In|Type|Required|Description|
|---|---|---|---|---|
|body|body|[APIWorkflowPromptRequest](./schemas.mdx#schemaapiworkflowpromptrequest)|true|API workflow prompt-generation payload.|
|viewId|path|string|true|The view's handle (unique per org). Not the internal database uuid.|

> Example responses
>
> 200 Response

```json
{
  "agentPrompt": "You are an API workflow assistant. Help the user complete Weather onboarding."
}
```

> 500 Response

```json
{
  "message": "string"
}
```

### Responses {#generate-an-api-workflow-agent-prompt-responses}

|Status|Meaning|Description|Schema|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|Generated API workflow agent prompt.|[APIWorkflowPromptResponse](./schemas.mdx#schemaapiworkflowpromptresponse)|
|500|[Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1)|JSON message response.|[MessageResponse](./schemas.mdx#schemamessageresponse)|
