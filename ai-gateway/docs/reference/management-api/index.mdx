REST API for managing API configurations in the WSO2 API Platform Gateway.

Base URLs:
* [http://localhost:9090/api/management/v1](http://localhost:9090/api/management/v1)
* [http://gateway-controller:9090/api/management/v1](http://gateway-controller:9090/api/management/v1)
